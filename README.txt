통화 자동 기록 연동 기능 - 적용 방법
=====================================

1) Supabase SQL Editor에서 migration_72_call_events.sql 전체 실행
   (새 테이블 2개 + 함수 1개만 추가하는 거라 기존 데이터는 전혀 안 건드려요)

2) 지금 쓰고 계신 사이트 폴더에 있는 .html / .js / .css 파일 전부를
   여기 들어있는 파일들로 교체해주세요.
   - 이번에 바뀐 파일: data.js, staff.html, expiry.html (실제 기능 추가)
   - 나머지 .html 파일들은 내용은 그대로고, 맨 위에 붙은 "?v=숫자" 버전
     번호만 전부 새 걸로 맞춰놨어요(브라우저가 예전에 저장해둔 캐시 말고
     새 data.js를 확실히 받아오게 하려고요). 그래서 전부 같이 교체하시는
     게 안전해요.

3) 교체 후 사이트에서:
   - "직원 관리" 화면 맨 아래 "📞 내 통화 자동 기록 연동"에서 본인 토큰 발급
   - 토큰 발급 버튼 옆 "Tasker 설정 방법 보기"를 펼치면 설정 방법이 나와요
   - 휴대폰에 Tasker 앱 설치하고 안내대로 설정
   - 전화 한 통 해보고 "만료회원 · TM" 화면 맨 위 "📞 자동 통화 기록함"에
     뜨는지 확인

주의: 통화 "번호·시간"은 자동으로 기록되지만, "무슨 내용으로 통화했는지"는
자동으로 안 채워져요. 익시오 같은 통화요약 앱에서 요약을 복사해서 자동
통화 기록함의 칸에 붙여넣고 저장하면 그게 TM 기록 메모로 들어갑니다.
