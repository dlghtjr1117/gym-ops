📞 내 통화 자동 기록 연동

내 휴대폰(안드로이드)에서 전화가 끝나면 자동으로 "신규상담" 화면의 자동 통화 기록함에 한 줄씩 쌓이게 하는 연동이에요. 아래 토큰을 발급받아서 Tasker 같은 자동화 앱에 설정해두면 돼요. 통화 "내용"까지 자동으로 채워지진 않고(번호·시간만 자동), 내용은 익시오 등에서 복사해서 직접 붙여넣어야 해요.

Tasker 설정 방법 보기
1. 플레이스토어에서 Tasker 앱 설치 (유료, 7,500원 1회 결제) 후 실행
2. 프로필 탭 → + → 상태(State) → 전화 → 통화중 선택 → 뒤로가기(저장)
3. 바로 뜨는 새 작업 창에서 + → net → HTTP Request 선택 후 아래처럼 입력:
Method: POST
URL:
Headers: apikey: Content-Type:application/json
Body: {"p_token":"(아래 발급받은 토큰)","p_phone":"%CNUM","p_duration_seconds":%CALLD,"p_direction":"unknown"}
4. 프로필 이름을 "통화 자동 기록" 같은 걸로 저장
5. 전화 한 통 해보고, "신규상담" 화면 맨 위 자동 통화 기록함에 뜨는지 확인해보세요
(Tasker 버전에 따라 메뉴 이름이 살짝 다를 수 있어요. 안 되면 화면 캡처해서 알려주시면 같이 봐드릴게요)
